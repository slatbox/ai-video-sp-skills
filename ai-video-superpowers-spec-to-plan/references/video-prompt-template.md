# 生视频提示词模板（分镜重现式）

每段 SEG 的最终视频 prompt：把第二步的 N 个分镜节点 + spec 的风格/氛围/台词填入下模板。@[storyboard] 换成 `storyboards/SEG-xx.png`，@[char1]/@[char2]… 换成实际参考图路径。**分镜节点只写到本段实际数量 Pxx**（板面剩余格为空白格，视频生成不涉及）。

## 模板全文

```text
@[storyboard] 是本视频的分镜蓝图——请逐镜头进行重现。每个 P## 阶段的画面均需在机位角度、景别、构图、动作调度、屏幕位置及运动方向上与对应的分镜格保持一致。请勿黏土预演 (clay-previs) 风格、空白人体模型、边框及杂乱标记。请按下方风格渲染全细节；文字描述与映射参考图共同定义所有视觉特征。
附加参考图仅定义最终外观，不涉及布局或动作调度。请将 @[char1] 作为 C1 最终外观的唯一依据，将 @[char2] 作为 C2 最终外观的唯一依据。
视觉风格：[填写整体画面风格]
动作语言：[填写核心动作体系]
视觉特效：[填写绑定在画面/物体上的专属特效]
摄影风格：[填写镜头与画质要求]
音频：[填写声音设计要求]
环境：[填写场景细节]
情感基调：[填写整体情绪与动作逻辑]
节奏与递进：[填写剪辑与速度曲线]
分镜节点：
P01：[填写分镜1：机位、景别、人物位置、核心动作、画面细节]
P02：[填写分镜2：机位、景别、人物位置、核心动作、画面细节]
……（逐条写到本段实际最后一格 Pxx，不写空格子）
```

## 填写规则

- **@[storyboard]**：写"本段分镜板（storyboards/SEG-xx.png，作为首张参考图传入）是本视频的分镜蓝图"；执行阶段把它作为第一张 `--image` 传入，人物/场景参考图随后
- **@[charN]**：改为"请将 <refs/char-x.png> 作为 <角色名> 最终外观的唯一依据"，本段出场的每个角色各一句
- **视觉风格**：取 spec 第 2 节"画面风格"栏（全局统一），可补质感/渲染细节
- **动作语言**：核心动作体系（身体重量感、惯性、speed ramp 等），无打斗段可写"日常动作的真实重量感与节奏"等
- **视觉特效**：绑定画面/物体的特效；无特效写"无，仅自然光影与尘埃等环境粒子"
- **摄影风格**：由本阶段确定的镜头设计汇总（本段 N 格的机位/景别/运动类型概括成一句风格要求）
- **音频**：声音设计（海螺 H3 支持音频输出时生效）；无要求写"无背景音乐，仅环境音"
- **环境**：取 spec 场景片段的环境描述，补时间/光线/空间结构
- **情感基调**：各角色的情绪与动作逻辑
- **节奏与递进**：剪辑/速度曲线（硬切/放缓/定格等，按本段 N 格的情绪弧线写）
- **分镜节点**：P01–Pxx 逐条填入（**只写实际分镜数**；机位、景别、人物位置、核心动作、画面细节），与分镜板已用格一一对应；台词直接写进对应格的描述里，台词时长须在段内可完成（对白 3~3.5 字/秒、旁白 3.5~4 字/秒）
- **连贯（承接上段）片段**：在"环境"后加一句"与上一镜头同一场景同一人物同一光照，紧接上一画面"（连贯性由该承接句 + 链式分镜板保证，执行阶段**不再**生成尾帧首帧图）
