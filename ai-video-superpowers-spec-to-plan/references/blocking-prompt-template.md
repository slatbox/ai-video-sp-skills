# 俯视场景调度图（Blocking Diagram）生成提示词模板

每段 SEG 在生成分镜板**之前**，先出一张俯视调度图，存 `<项目>/storyboards/SEG-xx-blocking.png`。
用途：给本段分镜板提供统一的**空间调度依据**——谁站在哪、从哪移动到哪、面向哪里、在哪里发生交互。分镜板各格共用同一套站位逻辑，避免各格之间人物位置/朝向随机漂移。
调度图**只作为分镜板的参考图**，不传给视频生成模型（plan.md 里写在单独的"调度图"字段，不写进"参考图"字段）。

## 模板全文

```text
【标题】
制作场景调度图页眉：采用适配场景风格的排版与清晰层级。仅包含以下一行引号内的文字："[SEG-xx · <场景简名> · 俯视调度图]"

【图面定义】
这是一张戏剧舞台调度式的俯视场景图（顶视图/鸟瞰图）：从正上方垂直俯瞰整个场景空间，只表现地面平面布局与人物站位、运动轨迹，不表现任何摄影机视角、景别或镜头框。场景按参考图以顶视投影呈现（地面、墙体、通道、大型陈设的平面相对位置须与场景参考图一致）。

【视觉风格】
明亮的黏土模型风格俯视预演图：哑光浅黏土质感的简化体块模型，仅使用柔和白与浅暖灰，背景明亮；人物为素体小人俯视形象，不同角色用其参考图服装的主色区分；运动轨迹用清晰的深色带箭头虚线表示（起点圆点、终点箭头，转折画折线）；无面部细节、无照片级写实、无高饱和色彩、无插画风格。

【站位与轨迹】
- 初始站位：[P01 时刻各角色位置，用场景内参照物描述，如"C1 靠近画面左侧石柱，C2 在门口"]
- 运动轨迹：[谁从哪里移动到哪里；带箭头虚线标出，方向与【动作节点】时间顺序一致；起点=P01 状态，终点=Pxx 状态]
- 朝向：[关键角色在关键节点的面向，用小人朝向表现]
- 交互点：[接触/对峙/交接发生的确切位置]
每个角色全图仅一个起点、一条轨迹（原地动作用小圆圈原地标记）。

【参考】
场景参考图为场景平面结构唯一依据（墙体、通道、大型陈设的相对位置必须一致）；人物参考图仅用于区分角色与服装主色；影响站位与通行的关键物品参考图须按其平面位置画出。
[若与上一段同一场景]另提供上一段调度图作为布局连贯依据：同一场景的平面结构、固定陈设位置必须完全一致，人物运动须自然衔接上一段的结束站位。

【文本规则】
可见文字仅限页眉标题一行。画面内不出现任何其他文字、数字、人物名标签、图例框、标注框、比例尺。

【动作节点】（仅作为站位与轨迹的时间依据，不绘制到图上）
P01 / [镜头标签] / [动作名]: [画面描述]
P02 / [镜头标签] / [动作名]: [画面描述]
……（至实际最后一格 Pxx 为止）
```

## 填写规则

- **时机**：第 2 步动作分镜设计完成后、第 3 步分镜板生成前，按 SEG 顺序逐张生成；每段一张。
- **主标题**：`SEG-xx · <场景简名> · 俯视调度图`（页眉仅此一行，模板里已含）。
- **站位与轨迹**：全部从【动作节点】倒推——P01 的各角色位置=初始站位，P 节点间的位移=轨迹；多人同场必须写清每人的参照物位置，避免模型自行摆位。
- **画面描述**只写空间关系与位移，不写风格词（板面固定为黏土俯视预演风）；镜头标签只进【动作节点】作时间依据，图上不表现机位。
- **竖屏项目**：`--ar 9:16`；横屏项目 `--ar 16:9`。其余参数与分镜板一致：`tt-image-2.5` + `version sunburst` + `--res 2K`。
- **挂图**：`--image` = 该段全部人物参考图 + 全部场景参考图 + 影响站位/通行的关键物品参考图；同场景连贯段另挂上一段调度图（放最后，仅作平面布局连贯依据）。
- **提交示例**：

```sh
python3 /var/minis/skills/zhike-image/scripts/image.py submit \
  --prompt "<组装好的调度图模板全文>" --ar 16:9 --res 2K --version sunburst \
  --image refs/char-a.png --image refs/char-b.png \
  --image refs/scene-1.png --image refs/prop-x.png \
  --image storyboards/SEG-<上一段>-blocking.png
```

- **下载落** `<项目>/storyboards/SEG-xx-blocking.png`；task_id 立即写入 `storyboards/.taskids.json`（与分镜板同一个文件）防丢。
- **出图核对**：场景平面结构与场景参考图一致（墙体/通道/大型陈设不错位）、出场人物齐全且服装主色可区分、轨迹方向与分镜 P 节点动作方向一致、画面内无多余文字；不合格重试 1 次（收紧站位/轨迹描述），仍失败标记"调度图待补"→ 分镜板降级为仅挂人物/场景/物品参考继续（记录到 plan 备注）。
- **重生成连锁规则**：与分镜板相同——改某段调度图或分镜板时，其后所有调度图与分镜板连带重生成。
