# 时长设计审核 · 子智能体任务书模板

供两个阶段共用，派 subagent_task（General Sub Agent）时把对应任务书全文写进 task（替换方括号，附上文件绝对路径）。子智能体只读文件、只做核算与判断，**不修改任何文件**；返回结构化结论文本。

**模板全文文件（组装时直接读取、替换方括号）**：
- A. spec 时长审核（brainstorm 阶段用）：`templates/audit-spec.txt`
- B. plan 时长审核（spec-to-plan 阶段用）：`templates/audit-plan.txt`（含台词标签 `<d>` 检查）

## 核算基准（两个审核共用）

- **中文语速**：对白 3~3.5 字/秒；旁白 3.5~4 字/秒；数字/外文/拗口词按 2.5 字/秒。每句另加 ~0.3s 句间停顿；情绪重读句 ×1.3。
- **动作/镜头时长**：每个分镜定格 1.5~3s（动作格 1.5~2s，氛围/表情/空镜/转场格 2~3s）。
- **合格线**：台词总秒数 + 动作呼吸余量（15~25%）≤ 段时长，且不低于段时长的 50%（低于 = 太稀疏）。
- 硬限制：单段 4~15s。

## 审核循环规则（两个阶段共用）

- 返回"不通过"→ 主智能体按清单修改 spec.md / plan.md → 再次派审 → 循环直到通过，**上限 3 轮**；3 轮仍不过，把剩余分歧点整理给用户裁决。
- 通过后：把审核轮次与结论写进文档对应"审核记录"栏（spec 第 9 节 / plan 末尾审核记录行）。
- 子智能体只核算不改文件，所有修改由主智能体执行，保持格式合规。
