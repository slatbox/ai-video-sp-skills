# 人物参考图 · 提示词模板与规则

> 供 ai-video-superpowers-brainstorm（及后续阶段复用）。自动生成人物参考图时必须遵守本文件规则。

## 为什么用"无头三视图 + 正脸特写"

为保证跨片段人物一致性，且避免身体/面部互相干扰——视频模型参考人物图时，全身像的脸常与正脸特写打架（脸不一致、或全身像脸部被当作标准脸）。拆成"无头身体 + 独立正脸"两部分，身份靠正脸、服装道具靠身体，各司其职。

## 图面规格

**一张横版 2K 图**（`--ar 16:9 --res 2K`），纯白背景无环境，左右两部分：

- **左侧：无头全身三视图**——同一角色正面、侧面、背面三个全身像水平并排，**颈部以上干净移除（无头、无脖子）**，服装发型道具三视图完全一致（随身道具如背包/相机随身体出现）；
- **右侧：正脸特写**——同一角色的正面头像特写，面部细节清晰（发型、胡须、眼镜、帽子、表情气质）。

## 提示词模板

```
<角色完整外貌描述：年龄/发型/发色/面部特征/服装款式颜色/随身道具/体型/气质>，角色设定图，画面分左右两部分，纯白背景无环境：左侧为无头全身三视图——同一角色躯干全身像三个（正面view、侧面view、背面view）水平并排，颈部以上干净移除，无头无脖子，服装道具三视图完全一致；右侧为同一角色的正脸特写肖像，<面部细节：发型/胡须/眼镜/帽子/表情气质>。横版2K，<画面风格关键词>，高质量角色设定图
```

调用示例：

```sh
python3 /var/minis/skills/zhike-image/scripts/image.py submit \
  --prompt "<按上述模板填充>" --ar 16:9 --res 2K --version flare \
  --image <项目风格图 refs/style-xxx.png，可选，保画风统一>
```

## 其他说明

- 用户上传的人物图也优先建议满足"无头全身三视图 + 正脸特写、单人、背景干净"（实在没有就全身单人照，脸清晰）。
- 生成后**展示给用户审核**，通过才落盘 `refs/char-<name>.png`；不通过按反馈改提示词重生成（最多 2~3 轮）。
- 注意：shell 直写到 `/var/minis/workspace`、`/var/minis/attachments` 在部分会话中会丢文件（app 文件层回退），**curl 下载直接落到 `/var/minis/shared/<project>/refs/`** 再稳妥。
