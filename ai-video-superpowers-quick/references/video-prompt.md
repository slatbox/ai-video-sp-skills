# 视频 prompt 组装模板（quick）

> 第 3 步组装提示词时**照抄本模板全部段落**，方括号占位逐项替换；本技能没有分镜板，因此不含 @[storyboard] 段，动作节点直接用文字 P 节点表达。首段参考声明句式保留，标签与 `--image` 顺序一一对应。

## 模板全文（组装时从此处复制）

```
请将 @[char1] 作为 C1 最终外观的唯一依据，将 @[char2] 作为 C2 最终外观的唯一依据（无人物则删此行）。@[scene1] 是场景结构与陈设的唯一依据。@[style] 定义整体画风（无风格图则删）。
视觉风格：[填写整体画面风格]
动作语言：[填写核心动作体系]
视觉特效：[填写绑定在画面/物体上的专属特效]
摄影风格：[填写镜头与画质要求]
音频：[填写声音设计要求]
环境：[填写场景细节]
情感基调：[填写整体情绪与动作逻辑]
节奏与递进：[填写剪辑与速度曲线]
动作节点：
P01：[填写动作节点1：机位、景别、人物位置、核心动作、画面细节]
P02：[填写动作节点2：…]
……（2~6 个节点，写到实际最后一格 Pxx 为止；节点总量与 duration 匹配，宁松勿密）

【台词标注规则】
本段所有发声台词（对白与旁白）必须用台词标签完整包裹，格式：<d>[Chinese]台词原文</d>。一句台词一个 <d> 标签（长台词可按句拆成多个标签，按实际节奏断句）；标签内只放台词原文，不加说话人名、动作描述或标点以外的任何内容；旁白同样用 <d> 包裹；不发声的内心独白/环境音不使用标签。
```

## 填写规则

1. **参考声明行**：有几个角色写几个 `@[charN]` 声明（C1/C2… 与角色编号对应）；无人物的纯景镜头删掉角色声明行，保留场景/风格声明。
2. **@[标签] 顺序 = `--image` 传入顺序**：建议顺序 = 人物图（char1、char2…）→ 场景图（scene1…）→ 物品图（prop1…）→ 风格图（style，若有），prompt 中首次出现顺序保持一致。
3. **台词**：台词直接写进对应 P 节点的画面描述里，用 `<d>[Chinese]…</d>` 包裹；一句一标签；旁白同样包裹；内心独白/环境音不包。
4. **P 节点数量**：2~6 个。每个节点一句话覆盖机位/景别/人物位置/核心动作/画面细节；节点节奏要与 duration 匹配（例：8s 配 3~4 个节点）。
5. **时长核算**：对白 3~3.5 字/秒、旁白 3.5~4 字/秒（含 ~0.3s 句间停顿），台词总秒数 +15~25% 动作余量 = 建议 duration（4~15 取整）。
6. 八个维度段（视觉风格…节奏与递进）**一段都不能漏**，没有的内容写"无"或留简洁描述，不要整段删除。

## 组装范例（咖啡广告，8s，16:9，无台词）

```
请将 @[char1] 作为 C1 最终外观的唯一依据。@[scene1] 是场景结构与陈设的唯一依据。
视觉风格：写实电影感实拍质感，暖色调
动作语言：日常自然动作，节奏轻快
视觉特效：蒸汽袅袅升腾，晨光光斑
摄影风格：浅景深，50mm 质感，缓慢推近
音频：咖啡机蒸汽声 + 轻快钢琴底乐
环境：清晨的城市咖啡馆窗边，木质吧台，阳光斜照
情感基调：温暖惬意，一天美好的开始
节奏与递进：由静到动，结尾定格微笑
动作节点：
P01：特写，咖啡机出液口，深色咖啡缓缓注入玻璃杯，油脂分层泛起，蒸汽升腾
P02：中景 @[char1] 端起咖啡杯转身面向窗边，晨光洒在侧脸
P03：近景，@[char1] 靠窗浅啜一口，满足微笑，窗外街景虚化，镜头缓慢推近定格
```
